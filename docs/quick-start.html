7 DAYS TO DIE

Moving your save between the two PCs

Two buttons, and the orange one is always the one you want. It works over your home network, or on a USB stick when you are away from it.

Set it up once on each PC

Two buttons appear near the top of the window the first time. Both are worth doing, and neither is asked again.

  1. Allow over the network. Lets the two PCs send saves straight to each other, with no stick involved. Windows asks for permission once - click Yes - and never asks again.
  2. Install on this PC. Puts the program on that PC so it starts with Windows and sits quietly next to the clock. This is what lets a PC notice by itself that the other one has come home with a newer save.

After that it mostly looks after itself

Play on the laptop anywhere, even with no internet. Come home, and the two PCs see each other. A message appears near the clock saying the laptop has a newer save. Open it, press the orange button, play.

The two buttons

  1. Close 7 Days to Die. It refuses to copy while the game is open, because copying a save mid-write makes a broken world.
  2. Press Send my saves on the PC you just played on.
  3. Press Bring the newer saves here on the PC you want to play on.

The orange button is always the right one

The program checks both sides and lights up the one you need. The other stays greyed out and says why, so there is nothing to work out.

Your mods come with it

A save made with mods needs those same mods on the other PC, or the world will not load properly. You do not have to do anything - the mods ride along with the save.

On the other PCWhat happens
It does not have the mod The mod is copied across and installed, with its settings.
It has the same mod already Nothing is touched.
It has the mod, but a different version or different settings Yours is kept. The incoming one is not installed over the top of it.
It has mods the other PC does not They are left exactly where they are. Nothing is removed.

Your mod settings are never written over

Most mods keep their settings inside their own folder, and the other PC cannot know how you have set yours up. So a mod that is already installed here is never replaced - even if the other PC has a newer one. If a mod cannot be copied for any reason, the save still goes across and the program says which mod it skipped.

It finds mods even if they were unzipped wrong

A mod downloaded as a zip often ends up one folder too deep, which is the usual reason a mod "does not work". The program looks inside those extra folders, finds the real mod, and puts it in the right place on the other PC.

Travelling, or the PCs are not on the same network

Use the USB stick exactly as before - run the program from the stick, press the orange button, carry it across, press the orange button there. Both ways work at any time, and you never have to say which one you are using.

What if it says something else?

It saysWhat to do
Everything matches Nothing to do. Both sides already hold the same save.
Close the game first 7 Days to Die is still running. Close it, then press Refresh.
No USB stick found Plug the stick in and wait a couple of seconds, or use the network instead.
Other PC: not switched on right now The other PC is off, asleep, or the program is not running on it. Use the stick, or start it over there.
Cannot find your saves The game has probably never been run on that PC. Run it once, quit, and try again.
One save needs you to choose Both PCs were played since they last matched. See below.

"These are two different saves"

Sometimes two PCs have a save with the same name that is not the same game at all - somebody else started their own. The program spots that and will not do it on its own. It tells you in plain words, names both saves side by side, and waits. If you decide to go ahead anyway, the save that was there is kept permanently as a backup you can put straight back.

It always tells you what it is touching

Every message names the save and the world - moving, backing up, restoring or replacing - so you can check it is the right one before anything happens.

"Both PCs were played"

This happens when someone played on each PC without moving the stick in between. The two worlds cannot be merged - nobody's tool can do that - so you pick which one to keep. The one you do not pick is not deleted. It goes into Backups and you can put it back at any time.

Nothing is ever deleted

Every time a save gets replaced, the old one is kept - every one of them, for good. A backup only ever disappears because you deleted it yourself. Click Backups at the bottom of the window to see them and put any of them back. If a transfer is interrupted - the power goes, the stick is pulled out - the save is put back the way it was next time you open the program.

Make a backup any time you like

Open Backups and press Back this save up now. It copies the save exactly as it is this second, before you try anything you are unsure about. Backups made this way are kept permanently.

Every backup explains itself

Inside each backup folder there is a file called READ ME - how to put this back.txt. It says which save it is, when it was taken, why it was kept, and how to put it back by hand - with plain folder copying, no program needed. So a backup still makes sense in a year, on a PC that has never heard of this tool.

Both people's characters travel together

A world holds a separate character for each person who has played in it, and the whole world moves as one piece. You do not need to do anything special for the second person.

Where can you keep the program?

Anywhere. It is a single file that needs nothing installed - run it from the USB stick, the Desktop, your Downloads folder, or a shared drive. If the place you run it from is read-only, it still works; it just keeps its settings on that PC instead of next to itself.

If something looks wrong, open a Command Prompt on that PC and run SaveSync.exe --diagnose. It writes a short report to your Temp folder that says exactly what it found and where.
